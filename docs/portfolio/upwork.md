# Telegram Lead Capture Bot With CRM Integration

**Role** · Python developer, Telegram bot and CRM integrations

**Portfolio description**

I built LeadRelay for service teams that receive enquiries in Telegram. A customer submits a guided request, a manager receives a scored lead card and can reply from the team chat. I wrote the form, scoring rules, encrypted storage, delivery worker and CRM connectors. The attached demo follows one plumbing enquiry through a simulated webhook outage and recovery. Both attempts carry the same lead ID.

**Skills** · Python · Telegram API · API Integration · CRM Automation · SQLAlchemy

## Standalone bot

I can set up the bot for a business using its own Telegram account, branding, services and working hours. The team receives enquiries in a private chat, assigns them to managers and follows up with the customer. The handoff includes the source, configuration example and setup instructions. Hosting, third-party accounts and the scope of installation are agreed separately.

## Integration with an existing workflow

I can connect a Telegram intake flow to your CRM or adapt the delivery component for an existing bot. We agree on the destination, field mapping, duplicate handling and what should happen when delivery fails. I test the mapping with a sample lead in your sandbox before enabling production delivery.
